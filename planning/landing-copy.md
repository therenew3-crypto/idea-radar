# 랜딩페이지 카피 (Phase 0 수요 측정용)

> 목적: 코드로 만들기 전, **결제 의향**을 측정하는 한 장짜리 랜딩.
> 핵심 = "무료로 만들기" CTA + (가짜) "Pro 시작하기" 결제 버튼 클릭률.
> 타깃: 개발 외주 프리랜서. 톤: 군더더기 없고 실용적, 신뢰감.
>
> ⚠️ 인터뷰에서 들은 **실제 표현**으로 헤드라인·페인 문구를 교체하세요. 아래는 출발점 초안.

---

## 1. Hero (첫 화면)

**헤드라인 (A안 — 시간 강조)**
> 견적서·계약서, 5분이면 끝.

**서브헤드**
> 한글·워드 복붙은 그만. 폼만 채우면 한국 표준 양식 PDF가 바로 나옵니다. 개발 외주 프리랜서를 위해 만들었어요.

**CTA (주)**: `무료로 만들기 →`
**CTA (보조)**: `샘플 PDF 보기`

---

### 헤드라인 대안 (인터뷰 후 A/B 테스트)
- **B안 (신뢰 강조)**: "변호사가 검수한 개발 외주 계약서, 5분 만에."
- **C안 (페인 강조)**: "매번 지난 견적서 찾아 복붙하고 계셨다면."
- **D안 (가격 강조)**: "월 9,900원으로 견적·계약 문서 무제한."

---

## 2. 문제 제시 (Pain)

> **이런 적, 있으시죠**
> - 새 프로젝트 때마다 지난 파일 찾아서 복붙, 금액·날짜 고치다 실수
> - 한글로 양식 맞추느라 표 깨지고 시간 날림
> - 계약서가 법적으로 괜찮은 건지 늘 찜찜
> - 보내고 나서 서명·도장은 또 따로

*(→ 인터뷰에서 가장 많이 나온 페인 2~3개로 교체)*

---

## 3. 해결 (Solution / How it works)

> **이렇게 끝납니다**
> 1. **폼 채우기** — 거래처·항목·금액만 입력
> 2. **실시간 미리보기** — 만들어지는 문서를 바로 확인
> 3. **PDF 받기** — 다운로드하거나 링크로 공유

---

## 4. 차별화 (Why us)

| | 우리 | 한글/워드 복붙 | 무료 템플릿 |
|---|---|---|---|
| 한국 표준 양식 | ✅ 정확 | 직접 맞춤 | 양식마다 제각각 |
| 변호사 검수 계약서 | ✅ | ❌ | ❌ |
| 5분 생성 | ✅ | 느림 | 보통 |
| 부가세 자동 처리 | ✅ | 수동 | 없음 |
| PDF·공유 링크 | ✅ | 수동 변환 | 제각각 |

*(전자서명·세금계산서는 "곧 출시" 배지로 표기 — 로드맵 신뢰 확보용)*

---

## 5. 신뢰 요소 (Trust)

- "개발 외주 프리랜서를 위해 설계된 표준 양식"
- "계약서 템플릿은 변호사 검수를 거칩니다" *(검수 완료 후에만 게시)*
- 고지: "표준 참고용 문서입니다. 중요한 계약은 전문가 검토를 권장합니다."
- *(인터뷰 참가자 후기 1~2개 확보되면 인용)*

---

## 6. 요금 (Pricing)

| Free | Pro |
|---|---|
| **0원** | **월 9,900원** |
| 월 3건 생성 | 무제한 생성 |
| PDF 다운로드 | 워터마크 제거 |
| | 곧: 전자서명·세금계산서 |
| `무료로 시작` | `Pro 시작하기` |

> **검증 단계 트릭**: `Pro 시작하기`를 누르면 실제 결제 대신
> "출시 준비 중이에요! 가장 먼저 알려드릴게요 — 이메일 남겨주세요" 모달.
> → **이 버튼 클릭 수 = 진짜 지불 의향 신호.**

## 7. 최종 CTA

> **문서 작업에 쓰던 시간, 일하는 데 쓰세요.**
> `무료로 만들기 →`

> *(또는 미출시 시)* **출시되면 가장 먼저 알려드릴게요.** `대기자 등록`

## 카피 작성 원칙 (수정 시 참고)
- 기능이 아니라 **결과**를 말한다: "PDF 생성" ❌ → "5분이면 끝" ⭕
- 추상어 금지: "혁신적 솔루션" ❌ → "지난 파일 복붙 그만" ⭕
- 타깃을 좁게 호명: "프리랜서 여러분" ❌ → "개발 외주 하시는 분" ⭕
- 거짓말 금지: 변호사 검수·후기는 **실제로 확보한 뒤에만** 게시
