# 샘플 문서 시안 (Phase 0 검증용)

인터뷰에서 프리랜서에게 보여줄 **견적서·계약서 시안**입니다.
"폼만 채우면 이런 게 5분 만에 나온다"를 눈으로 보여주는 용도.

| 파일 | 내용 |
|---|---|
| `quote-sample.html` | 견적서 시안 (개발 외주 랜딩페이지 프로젝트) |
| `contract-sample.html` | 소프트웨어 개발 용역 계약서 시안 (12개 조항) |

## 보는 법 / PDF로 만드는 법

1. 파일을 **브라우저로 열기** (더블클릭 또는 드래그)
2. `Ctrl/Cmd + P` → 대상을 **"PDF로 저장"** 선택
3. 용지 A4, 여백 기본값 → 저장

> 한글 폰트는 Google Fonts(Noto Sans KR)를 불러옵니다. 오프라인이면 시스템 한글 폰트로 대체 렌더됩니다.
> 화면 좌상단의 주황색 "시안" 배지는 인쇄/PDF에는 나오지 않습니다.

## 인터뷰에서 쓰는 법

- 질문지(`../planning/interview-guide.md`) **D단계(13번)**에서 이 PDF를 보여주세요.
- 보여준 뒤 반응을 기록: "이거 실제로 쓰시겠어요?" → "9,900원에 결제하시겠어요?"
- 시안을 보며 나오는 **"이건 이렇게 바꿔야 해요"** 피드백이 곧 v1 요구사항입니다.

## 주의

- 데이터(상호·금액·계좌 등)는 전부 **가상 예시**입니다.
- 계약서는 표준 참고용이며, 출시 전 **변호사 검수**가 필요합니다 (문서 하단에 고지 포함).
- 이 HTML은 추후 Next.js 템플릿의 **시각 레퍼런스**로도 사용합니다.
